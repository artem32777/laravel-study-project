## Первоначальная настройка из корня проекта:

```bash
docker compose up -d
composer run setup
```

`setup` устанавливает PHP- и JavaScript-зависимости, создаёт `.env`, если его ещё нет, генерирует ключ приложения,
выполняет миграции и собирает фронтенд. Перед запуском проверьте параметры подключения к базе данных в `.env` (при
необходимости скопируйте `.env.example`).

Запуск проекта:

```bash
docker compose up -d
composer run dev
```
